# Meat Paw review evidence

The isolated browser runner uses the production scripts, real keyboard events
and Canvas rendering. The MQ7-completed state and entry placements are fixtures;
the local ambush is entered by ordinary walking. Both continuous presentation
and Legacy Regional Fallback were exercised. Native 512×480 captures and 2×
nearest-neighbour captures are included.

- `bounty-notice-*`: MQ7-gated board notice and warning.
- `passage-before-*`, `bear-emerges-*`, `cornered-*`: original terrain and emergence.
- `esla-warning-*`: Esla alone uses green dialogue.
- `battle-*`, `pounce-*`: shared-engine presentation. The last Pounce image follows
  two separate attacks: one felled Esla, the next felled Lély; Pounce never targets
  both characters at once.
- `victory-*`, `payment-*`, `passage-cleared-*`: authenticated clearance and payment.

The browser suite uses a deterministic defeat and boosted victory stats to check
lifecycle, not to measure balance. No human full-world playthrough is claimed.
Attack arithmetic, misses, Fallen selection, no escape, tamper rejection and
read-only replay are covered by focused suite 355. Ordinary character balance
and the cost of preparation remain human playtest judgments.

`verification.json` records the final tests, exact incremental file inventory,
and the unchanged branch/HEAD. `final-status.txt` includes all earlier uncommitted
work; it must not be mistaken for files authored solely for Meat Paw.
